# authdog/.github

Public profile for the [Authdog](https://github.com/authdog) organization.

GitHub renders [`profile/README.md`](profile/README.md) on the [organization page](https://github.com/authdog). Logos sit next to that file so the relative image paths resolve.

| Path | Purpose |
| --- | --- |
| [`profile/README.md`](profile/README.md) | Organization profile |
| [`profile/logo-light.svg`](profile/logo-light.svg) | Logo, light mode |
| [`profile/logo-dark.svg`](profile/logo-dark.svg) | Logo, dark mode |
