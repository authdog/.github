Welcome to [Authdog](https://www.authdog.com) — an enterprise-ready CIAM (Customer Identity and Access Management) platform built for the AI era. We help developers ship authentication, authorization, and governance for both human users and AI agents, without building and maintaining identity infrastructure in-house.

Authdog runs on Cloudflare's global edge network across 330+ cities, with a median authentication latency of ~24ms.

## What we offer

- **Authentication** — pre-built, customizable UI for sign-up, sign-in, user profiles, MFA, and passkeys/passwordless login
- **B2B & Enterprise** — organization management, enterprise SSO, and SCIM provisioning
- **AI-native identity** — Token Vault for secure delegated API access, fine-grained authorization for RAG pipelines, and MCP (Model Context Protocol) security
- **Authorization & governance** — fine-grained, policy-based access control built on Open Policy Agent
- **Threat mitigation** — bot detection and abuse protection out of the box
- **Cloud Console** — a no-code web console to configure every security aspect of your application, with audit logging and webhooks
- **SDKs** — for Next.js, React, Vue, SvelteKit, Angular, Express, FastAPI, Go, Rust, and more

Built on open standards: OAuth 2.0, OpenID Connect, and WebAuthn/passkeys.
